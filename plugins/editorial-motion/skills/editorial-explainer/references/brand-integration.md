# Brand integration — light touch

Applies to **editorial-explainer**, **premium-product-motion** and
**imagery-motion**. Work is produced for many clients, not one. Essential's own
system (`essential-tokens.md`) is just the case where the client is Essential.

## The rule

**Minimum viable brand: one typeface in the right register, and one colour that
connects. Everything else neutral.**

That is genuinely almost all of it. A piece reads as a client's when the type
feels like theirs and one colour ties back to them. Past that point, extra brand
assets stop adding recognition and start making the work look like a brand
guidelines document instead of a piece of communication.

## What to take

**A typeface in the right register.** Match the *character*, not necessarily the
exact licence — a neutral grotesque for a grotesque brand, a humanist sans for a
warmer one, a serif only where the brand actually uses one. If the licensed face
isn't available, use the brand's own stated fallback before inventing a
substitution, and say which you used.

**One accent colour.** The colour that carries the mark that proves the finding.
It should be recognisably the client's, and it should be the *only* saturated
thing in the frame.

**A neutral that isn't grey-by-default.** Take the brand's own ink and surface
values if it has them. A neutral biased slightly toward the accent reads as
chosen; a pure mid-grey reads as unconsidered.

## What to leave

- **The rest of the palette.** A brand having eight colours is not permission to
  use eight colours. Secondary and tertiary colours mostly exist for interface
  states, not for data or editorial work.
- **Brand patterns and motifs.** Dot fields, wave marks, geometric devices —
  these belong on covers and templates, not scattered through a data piece as
  dividers. Using one because it exists is over-branding, and it dates the work
  to a guidelines document.
- **Repeated logos.** Once, small, in a corner, or not at all. Never as a
  recurring decorative element.
- **Sub-brand colours** unless the work genuinely belongs to that sub-brand.
- **Illustration styles** from the brand's marketing material, which are usually
  built for a different job than explaining a number.

## The test

Someone who knows the client should recognise the work as theirs. Someone who
doesn't should see a clear, well-made graphic — not a branded artefact.

If a brand element is present and you can't say what job it does in *this*
frame, remove it.

## Practical order

1. Ask what the client's typeface and accent colour are. If unknown, ask —
   don't guess from a logo.
2. Fill the role slots in **editorial-explainer**: ground, ink, muted, accent,
   and secondary only if the data actually diverges.
3. Set everything else from the neutral scale.
4. Stop.

## When there is no brand

Pick a neutral system and say so. A restrained, well-proportioned piece with one
considered accent is a better default than an invented brand identity, and it
leaves the client free to slot theirs in later.
