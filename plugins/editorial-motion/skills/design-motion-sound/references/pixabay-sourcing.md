# Pixabay sound-effects sourcing

Checked against Pixabay's Content License Summary, Terms of Service and public
API documentation on 12 August 2026. Re-check the live terms when sourcing.

## Supported workflow

1. Search the Pixabay Sound Effects website manually for a physical cause,
   material and duration, such as `paper swipe short`, `soft UI tick` or
   `low impact dry`.
2. Open promising item pages and audition them against the animation.
3. Download only selected files. Do not scrape results or systematically copy
   the library.
4. Record the item-page URL, contributor, downloaded filename, date and licence
   in the project rights log.
5. Store the downloaded file locally with the project. Do not hotlink it.

## API limitation

The public Pixabay API documentation describes search for images and videos. It
does not document sound-effect or audio search. Do not build against an
undocumented endpoint or scrape the site. Use human-selected website downloads,
or integrate another audio service only after checking its terms and permissions.

## Client safeguard

For material with meaningful reputational or commercial exposure, keep the
rights log and ask the user to approve final SFX selections. Escalate uncertain
samples, voices, recognisable brands or disputed content for specialist review.
